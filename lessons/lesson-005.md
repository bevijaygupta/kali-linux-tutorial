## Important concepts

### Terminal, shell, command line

The terminal is the window that accepts text and displays output. The shell is the program inside it that interprets commands, such as Bash or Zsh. The command line is the interface itself — the line where you type. Understanding the separation helps when you change shells or read documentation.

### Read the prompt

A typical Kali prompt shows the username, hostname and current directory, ending in $ for a normal user or # for root. If you see #, you are operating with full administrative power, so slow down and check each command before pressing Enter.

## FAQ

### Do I have to use the terminal in Kali Linux?

You can use graphical tools, but most security tooling is designed for the command line. Terminal skills make you faster and more precise.

### What does the # symbol in the prompt mean?

It usually means you are running as root, the administrative account. Commands run as root can change or break the system, so verify them first.
