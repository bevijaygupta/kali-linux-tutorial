## Important concepts

### Trust in unauthenticated protocols

ARP has no authentication: a host accepts a reply claiming an address belongs to a MAC. DNS without DNSSEC also trusts responses. Spoofing exploits that missing verification, which is why the defences focus on validating the claim.

### Defence in depth

Dynamic ARP inspection, DHCP snooping, static ARP entries, DNSSEC, encrypted protocols and network segmentation each raise the cost of spoofing. No single control eliminates it, especially on hostile local networks.

## FAQ

### How is ARP spoofing different from IP spoofing?

ARP spoofing manipulates local address resolution so traffic flows through the attacker. IP spoofing forges the source address in packet headers and usually prevents return traffic from reaching the sender.

### Does HTTPS prevent DNS spoofing?

HTTPS certificate validation makes it hard to impersonate a site even if DNS is poisoned, which is why certificate warnings must never be ignored.
