## About this chapter

Chapter 19 is a productivity chapter. It covers Tab completion, the arrow keys, Ctrl+R history search, Ctrl+A and Ctrl+E for line navigation, Ctrl+U and Ctrl+K for deleting text, Ctrl+L to clear the screen, Ctrl+C to stop a running command, and !! and !n to repeat commands.

## What you will learn

- How to auto-complete commands and filenames with Tab
- How to reuse earlier commands with the arrow keys
- How to search command history with Ctrl+R
- How to jump to the start or end of a line
- How to delete text quickly with Ctrl+U and Ctrl+K
- How to stop a stuck command with Ctrl+C

## Important concepts

### Readline shortcuts are universal

These key bindings come from the Readline library used by Bash and many other shells. They work in most Linux terminals, so the time invested pays off across distributions and tools.

### Ctrl+C sends an interrupt

Pressing Ctrl+C sends SIGINT to the foreground process. Most programs stop, but some ignore it or need a different signal. Knowing how to interrupt a runaway scan or a frozen pager is basic operational safety.

## Practical notes

Practise each shortcut until it becomes muscle memory. No special setup is required.

| Command | What it does |
| --- | --- |
| `Ctrl+R` | Search backwards through command history. |
| `Ctrl+A / Ctrl+E` | Jump to the beginning or end of the current line. |
| `Ctrl+U / Ctrl+K` | Delete text before or after the cursor. |
| `Ctrl+L` | Clear the screen without losing the current line. |
| `Ctrl+C` | Interrupt the running foreground command. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What is the difference between Ctrl+C and Ctrl+Z?

Ctrl+C interrupts and usually terminates the process. Ctrl+Z suspends it and returns you to the shell, where it can be resumed with fg or bg.

### Does Tab completion work for command options?

It completes commands and paths by default. Many shells can also complete options when completion packages are installed.
