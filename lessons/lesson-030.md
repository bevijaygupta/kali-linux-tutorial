## Important concepts

### Layer 2 identity

A MAC address identifies a network interface on the local segment. It is used by switches and wireless access points, while IP addresses handle routing across networks. Captive portals, hotel networks and some access controls key on MAC addresses, which is why changing one can bypass simplistic restrictions.

### Temporary and reversible

MAC spoofing changes the address the operating system presents, not the burned-in hardware address. It lasts until reboot or until you restore it. Record the original address before changing it.

## Practical notes

Use your own lab interface. Replace eth0 with your actual interface name from ip link.

| Command | What it does |
| --- | --- |
| `ip link show` | Identify the interface and its current MAC address. |
| `sudo ip link set eth0 down` | Bring the interface down before changing its address. |
| `sudo macchanger -r eth0` | Assign a random MAC address. |
| `sudo ip link set eth0 up` | Bring the interface back up. |
| `sudo macchanger -p eth0` | Restore the original hardware address (interface down first). |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Does changing my MAC address hide me on the internet?

No. It only changes your layer-2 identity on the local network. Destinations still see your public IP address.

### Why does macchanger fail with 'interface is up'?

The interface must be down while the address changes. Run ip link set <interface> down, change the MAC, then bring it back up.
