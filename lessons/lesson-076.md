## Important concepts

### Page context is the limit

BeEF modules run inside the hooked page's origin and browser context. They can manipulate the DOM, request resources and gather browser details, but the same-origin policy still constrains access to other sites.

### Chaining increases impact

A hook can gather information that helps choose a browser exploit, and a successful exploit can yield a deeper session. This is why client-side defence combines patching, content security policy and user awareness rather than relying on one control.

## FAQ

### Does BeEF work if JavaScript is disabled?

No. The hook depends on JavaScript execution in the page. Script blockers and strict policies prevent it.

### What is the best defence against BeEF-style attacks?

Keep browsers updated, block untrusted scripts, deploy a restrictive Content Security Policy and educate users about suspicious pages.
