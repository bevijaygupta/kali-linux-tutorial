## About this chapter

Chapter 41 profiles a website before testing it. It explains website footprinting, then uses WhatWeb to identify technologies, Whois to read domain registration details and Dirb to discover directories and files. The lesson closes by showing how the three tools answer different questions about the same target.

## What you will learn

- What website footprinting is and why it precedes testing
- How WhatWeb identifies CMS, frameworks and server technologies
- How Whois reveals registration and ownership details
- How Dirb performs content discovery with wordlists
- How to read and cross-check results from each tool
- Why discovered paths require authorization before access

## Important concepts

### Three layers of website recon

WhatWeb answers what the site runs, Whois answers who registered the domain and when, and Dirb answers which paths exist. Together they build a profile that guides later testing without sending exploit traffic.

### Content discovery is noisy

Dirb requests many candidate paths. Results include redirects, soft-404 pages and false positives, so verify interesting findings with a normal request and record status codes and response sizes.

## Practical notes

Use your own lab web app or a site you have written permission to assess.

| Command | What it does |
| --- | --- |
| `whatweb https://example.com` | Fingerprint web technologies. |
| `whois example.com` | Read domain registration details. |
| `dirb https://example.com /usr/share/wordlists/dirb/common.txt` | Discover common paths with a wordlist. |
| `dirb https://example.com -o dirb.txt` | Save content-discovery results to a file. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What is the difference between WhatWeb and Dirb?

WhatWeb identifies the technologies a site uses. Dirb looks for existing paths and files using a wordlist.

### Is Whois information public?

Registration data is published through Whois, although privacy services may mask personal details.
