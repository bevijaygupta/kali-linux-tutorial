## Important concepts

### Parallelism is a trade-off

Medusa can test multiple hosts and credentials concurrently. That improves throughput against tolerant services but increases the chance of lockouts, dropped connections and inaccurate results on fragile targets.

### Module-driven design

Each service has a module that knows the protocol's login exchange. Using the wrong module or port produces failures that look like wrong passwords, so verify the service and port first.

## FAQ

### Is Medusa faster than Hydra?

It can be, because of its parallel model, but real speed depends on the service, network latency and defensive controls.

### What does the -M option do?

It selects the service module Medusa uses to speak the target protocol.
