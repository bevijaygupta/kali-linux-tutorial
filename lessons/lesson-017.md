## About this chapter

Chapter 17 goes deeper into symbolic permissions. Starting from a string like -rwxr-xr--, it explains the user, group and others triads, then shows how to add, remove and set permissions with +, - and =, including combined changes such as u+x,g-w. Before-and-after ls -l output makes the effect visible.

## What you will learn

- How to read a permission string character by character
- What u, g, o and a mean in symbolic mode
- How to add permissions with +
- How to remove permissions with -
- How to set exact permissions with =
- How to combine several changes in one chmod command

## Important concepts

### Symbolic mode is relative

Symbolic changes modify the existing mode instead of replacing it. u+x adds execute for the owner and leaves every other bit untouched. That makes symbolic mode safer when you only need to adjust one permission.

### Equals replaces the triad

The = operator sets a triad exactly. o=r removes write and execute from others and leaves read. Combining classes, such as ug=rw, applies the same exact setting to both.

## Practical notes

Watch the permission string change after every command.

| Command | What it does |
| --- | --- |
| `ls -l script.sh` | Record the starting permissions. |
| `chmod u+x script.sh` | Add execute for the owner only. |
| `chmod g-w notes.txt` | Remove write from the group. |
| `chmod o=r notes.txt` | Set others to read only. |
| `chmod u+x,g-w,o=r notes.txt` | Apply several changes in one command. |
| `chmod a+r notes.txt` | Add read for all classes. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What does the a in chmod a+r mean?

It means all three classes together: user, group and others.

### What is the difference between + and = in chmod?

Plus adds a permission to what already exists. Equals sets the triad to exactly the permissions you list, removing anything else.
