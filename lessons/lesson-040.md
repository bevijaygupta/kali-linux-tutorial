## About this chapter

Chapter 40 connects scanning to vulnerability research. After Nmap reveals a service and version, Searchsploit searches the local Exploit-DB archive for documented issues in that software. The lesson covers searching by name and version, reading results, filtering, viewing and copying an entry, updating the database, and where this fits in a penetration test.

## What you will learn

- What Searchsploit and Exploit-DB are
- How to search by software name and version
- How to read and filter search results
- How to view an exploit entry and copy it to a working directory
- How to update the local Exploit-DB archive
- Why a public exploit match is not proof of exploitability

## Important concepts

### Offline research

Searchsploit queries a local copy of Exploit-DB, so it works without sending requests to the target. It is a research aid: results describe documented vulnerabilities, not confirmation that your specific target is vulnerable.

### Validate before exploiting

A version banner can be inaccurate, backported patches can remove a vulnerability, and exploit code may be unreliable or destructive. Validation in an isolated lab comes before any exploitation, and exploitation requires authorization.

## Practical notes

Search using a version you found in your own lab scan, then inspect the entry without running it.

| Command | What it does |
| --- | --- |
| `searchsploit apache 2.4` | Search the local archive for matching software. |
| `searchsploit -t apache` | Search titles only for a narrower result set. |
| `searchsploit -e "Apache 2.4.49"` | Perform an exact match search. |
| `searchsploit -m 50383` | Copy an exploit entry into the current directory by EDB ID. |
| `sudo searchsploit --update` | Update the local Exploit-DB archive. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Does Searchsploit test my target?

No. It searches a local database of documented exploits. You still have to validate whether the target is affected.

### How do I update Exploit-DB?

Run sudo searchsploit --update, which refreshes the local archive from the Exploit-DB repository.
