## About this chapter

Chapter 48 completes the SQL injection tool trio with sqlsus, a MySQL-focused interactive tool. It explains how sqlsus differs from SQLMap and jSQL, how to start it with a target configuration, how its interactive shell enumerates and extracts data, and when a MySQL-specific workflow is useful.

- How the interactive shell enumerates databases and tables
- How data extraction works in the tool
- When to choose sqlsus over the alternatives

## Important concepts

### Three approaches to the same vulnerability class

SQLMap is command-line and highly automated, jSQL is graphical, and sqlsus offers an interactive shell with a MySQL focus. Learning multiple interfaces builds a mental model of the underlying technique rather than dependence on one tool.

### Configuration-driven testing

sqlsus separates target details into a configuration file before opening its shell. That structure makes repeatable tests easier, but it also means the configuration must be accurate and scoped to an authorized lab target.
