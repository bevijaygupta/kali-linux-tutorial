- How to rename files and why mv differs from cp

## Important concepts

### Database search versus live search

locate queries a pre-built index, so it is extremely fast but only as current as the last updatedb run. find walks the actual file system, which is slower but always current and supports filters for size, type, permissions and modification time.

### mv moves and renames

mv changes a file's path. If the destination is another directory, the file moves into it. If the destination is a new name in the same directory, the file is renamed. Unlike cp, no copy remains at the original path.

## Practical notes

Practise searching for files you created, then move and rename them.

| Command | What it does |
| --- | --- |
| `locate notes.txt` | Search the locate index for a filename. |
| `sudo updatedb` | Refresh the locate database after creating new files. |
| `find . -name "*.txt"` | Search the current tree for text files. |
| `mv notes.txt archive/` | Move a file into a directory. |
| `mv oldname.txt newname.txt` | Rename a file in place. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Why does locate not find a file I just created?

Its database has not been refreshed. Run sudo updatedb, or use find for an immediate live search.

### Can mv rename a directory?

Yes. Moving a directory to a new name in the same parent directory renames it, including all its contents.
