## About this chapter

Why does sort put 10 before 2? Chapter 12 answers that question and turns the confusion into a practical lesson on text processing. It covers alphabetical sorting, numeric sorting with -n, reverse order with -r, column selection with -k, duplicate removal with -u, and combining sort with other commands through pipes.

## What you will learn

- Why default sort is lexicographic rather than numeric

- How to sort numbers correctly with sort -n
- How to reverse output with -r
- How to sort by a specific column with -k
- How to remove duplicate lines with -u and combine commands with pipes

## Important concepts

### Lexicographic versus numeric order

By default sort compares text character by character, so "10" comes before "2" because "1" sorts before "2". The -n flag tells sort to interpret fields as numbers, which is what you want for sizes, counts and ports.

### Pipes make small tools powerful

The pipe operator sends the output of one command into another. For example, a command that lists login attempts can be piped into sort and then into uniq to count repeated addresses. This composition is the heart of Unix-style text processing.

## Practical notes

Create a small list of numbers and words, then compare the output of each option.

| Command | What it does |
| --- | --- |
| `sort names.txt` | Sort lines alphabetically. |
| `sort -n numbers.txt` | Sort numerically. |
| `sort -r names.txt` | Sort in reverse order. |
| `sort -k2 -n data.txt` | Sort by the second column numerically. |
| `sort -u names.txt` | Sort and remove duplicate lines. |
| `cut -d: -f1 /etc/passwd \| sort` | Extract usernames and sort them using a pipe. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Why does sort put 10 before 2?

Default sort compares text, not numbers. Add -n to sort numerically.

### How do I remove duplicates while sorting?

Use sort -u, or sort followed by uniq if you need to count occurrences.
