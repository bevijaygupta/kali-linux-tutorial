## Important concepts

### Format, length and context

Hash length and character set narrow the possibilities, but several algorithms produce similar-looking values. Context such as the source system, a prefix like $2y$ or $6$, and the application's documentation are stronger evidence than length alone.

### A guess is not a verification

Hash-Identifier returns possibilities. The reliable test is to crack a candidate or verify a known plaintext. Choosing the wrong format wastes time and can produce confusing failures.

## FAQ

### Can Hash-Identifier crack a password?

No. It only suggests which algorithm produced the hash. Cracking requires a separate tool and wordlist.

### What if the tool lists several possible types?

Use context and test candidates. Formats with distinctive prefixes, such as bcrypt's $2y$, are easier to confirm.
