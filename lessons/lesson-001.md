## Important concepts

### Kali Linux is a tool collection, not a magic button

Kali Linux is a free, open-source, Debian-based distribution maintained by OffSec (formerly Offensive Security). Its value is that hundreds of security tools are pre-installed and pre-configured, which removes hours of setup work. The tools still require a human who understands networking, Linux and testing methodology, so Kali accelerates skilled work rather than replacing it.

### Kali versus Ubuntu

Ubuntu is tuned for everyday desktop use and servers. Kali is tuned for security assessment: it ships with Nmap, Metasploit, Wireshark, Burp Suite and many other tools, and it is not intended as a daily-driver operating system. Both are Linux distributions, so learning one builds transferable skills for the other.

## FAQ

### Should a complete beginner start with Kali Linux?

Kali is an excellent place to learn cybersecurity, but it is easier once you are comfortable with basic Linux concepts. This course starts from fundamentals, so a motivated beginner can follow along.

### Is Kali Linux only for hacking?

No. It is used for authorized penetration testing, vulnerability assessment, digital forensics, incident response, security research and general Linux learning.
