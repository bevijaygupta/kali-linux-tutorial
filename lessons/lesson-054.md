## Important concepts

### Combinatorial growth

Each added character position multiplies the search space. An eight-character lowercase-only space is 26^8; adding digits and symbols increases it enormously. Always calculate the size before generating, or you may fill the disk.

### Patterns encode intelligence

If you know a password starts with a company name and ends with four digits, a Crunch pattern encodes that assumption and avoids generating irrelevant combinations. That is far more efficient than blind brute force.

## Practical notes

Generate small lists first so you can inspect them. The syntax is length min, length max, character set.

| Command | What it does |
| --- | --- |
| `crunch 4 4 0123456789` | Generate all four-digit numeric combinations. |
| `crunch 6 8 abc123 -o list.txt` | Generate six- to eight-character combinations and save to a file. |
| `crunch 8 8 -t @@@@2024 -o patterned.txt` | Use a pattern where @ stands for lowercase letters. |
| `du -h list.txt` | Check the size of the generated wordlist. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### How do I estimate a Crunch wordlist size?

Raise the character-set size to the length for fixed-length output, then sum across lengths. Crunch prints the number of lines before generating.

### What does the @ symbol mean in a Crunch pattern?

It represents a lowercase letter placeholder. Other symbols represent uppercase letters, digits and symbols as documented by the tool.
