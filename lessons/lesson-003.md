## About this chapter

Downloading the wrong ISO is a real risk: fake Kali images can contain malware before you run your first command. ## Important concepts

### Choose the image that matches your plan

The Installer image installs Kali onto a disk. The Live image runs from removable media and can optionally install. The Network Installer downloads packages during installation and is small. Pre-built Virtual Machine images are ready to import into VirtualBox or VMware and are the quickest safe starting point for a lab.

### Checksum verification

Kali publishes a SHA256SUMS file next to its images. Computing the hash of your downloaded ISO and comparing it with the published value confirms the file arrived intact and matches what the Kali project signed. A mismatch means you should delete the file and download it again.

## Practical notes

Download only from kali.org, then verify the image before importing or installing it.

| Command | What it does |
| --- | --- |
| `sha256sum kali-linux-*.iso` | Print the SHA256 hash of the downloaded image. |
| `cat SHA256SUMS` | Show the published hashes so you can compare them with your result. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Which Kali Linux image should a beginner download?

For a first lab, the pre-built Virtual Machine image for VirtualBox or VMware is the simplest. Choose the Installer image if you plan to install Kali on real hardware.

### What if the checksum does not match?

Do not use the file. Delete it, download again from the official site, and verify once more. A repeated mismatch suggests a corrupted download or a tampered source.
