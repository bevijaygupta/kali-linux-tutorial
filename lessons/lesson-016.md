## Important concepts

### The permission triad

Permissions are assigned to the owner (user), the group and others. Each gets read, write and execute bits. For a file, execute means it can run as a program. For a directory, execute means you can enter it and read means you can list its contents.

### Octal arithmetic

Read is 4, write is 2 and execute is 1. Add the values for each triad: 7 is rwx, 5 is r-x, 6 is rw- and 4 is r--. That is why 755 means owner rwx, group r-x, others r-x. 777 grants everyone full access and is almost never appropriate.

## Practical notes

Practise on a disposable script and a test file. Check each change with ls -l.

| Command | What it does |
| --- | --- |
| `ls -l script.sh` | Inspect the current permissions. |
| `chmod 755 script.sh` | Set owner rwx, group r-x, others r-x. |
| `chmod 644 notes.txt` | Set owner rw-, group r--, others r--. |
| `chmod +x script.sh` | Add execute permission for the relevant users. |
| `chmod u+x script.sh` | Add execute only for the owner. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What does chmod 755 mean?

The owner can read, write and execute; group and other users can read and execute. It is common for scripts and directories that should be usable but not world-writable.

### Why is chmod 777 bad?

It gives every user write and execute access. That enables tampering, privilege escalation and accidental damage.
