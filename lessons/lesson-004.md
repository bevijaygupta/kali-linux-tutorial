## Important concepts

### Virtual machine networking

NAT gives the guest internet access through the host and hides it behind the host's address, which is convenient but limits inbound connections. Bridged mode puts the guest directly on your physical network, which is useful for network labs but exposes it to that network. Host-Only creates a private network between host and guest and is ideal for isolated practice.

### Plan resources before you start

Give Kali enough RAM (typically 2–4 GB) and at least two CPU cores if your host allows it. Enable 3D acceleration only if your GPU and drivers support it. Snapshots let you roll back after experiments, so take one immediately after installation.

## Practical notes

The chapter is a guided installation. Keep VirtualBox and the Extension Pack at matching versions to avoid driver and USB problems.

## FAQ

### Do I need VirtualBox to learn Kali Linux?

No, but it is the most common free option. VMware and Hyper-V also work, and Kali can run on bare metal if you accept the risk.

### Which network mode should I use for a hacking lab?

Host-Only for isolated practice, NAT for internet access without exposing the VM. Bridged only on networks you control and are authorized to test.
