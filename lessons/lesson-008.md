## Important concepts

### Absolute versus relative paths

An absolute path starts at the root, for example /etc/apt. A relative path begins from your current directory, for example ../logs. Absolute paths work from anywhere; relative paths are shorter but depend on where you are.

### Special directory names

A single dot means the current directory, two dots mean the parent, tilde means your home directory and a dash returns to the previous directory. These are shell conveniences that keep long paths manageable.

## Practical notes

Run these from your home directory and use pwd after each move to confirm your location.

| Command | What it does |
| --- | --- |
| `pwd` | Show the current directory. |
| `cd /etc` | Move using an absolute path. |
| `cd ..` | Move up one directory. |
| `cd ~` | Return to your home directory. |
| `cd -` | Switch back to the previous directory. |
| `touch practice.txt` | Create an empty file in the current directory. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What is the fastest way back to my home directory?

Run cd with no arguments or use cd ~. Both return you to your home directory.

### What does cd - do?

It switches to the directory you were in before the current one, which is useful when toggling between two working folders.
