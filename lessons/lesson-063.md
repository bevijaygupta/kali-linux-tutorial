## About this chapter

Chapter 63 explains why Wireshark cannot see another machine's traffic by default and the legitimate ways to capture it. It covers switched-network behaviour, SPAN and port mirroring, ARP spoofing as a man-in-the-middle technique, tools such as arpspoof and Ettercap, remote capture over SSH with tcpdump, and gateway capture. Authorization is a recurring theme.

- How to pipe remote capture over SSH with tcpdump
- Why capture on a gateway or router sees more traffic

## Important concepts

### Mirroring is the clean method

A managed switch can copy traffic from one port to another. This is the standard, authorized way for administrators to feed an analyser. It requires control of the switch and does not alter traffic.

### ARP spoofing is intrusive

ARP spoofing poisons a host's cache so it sends traffic through the attacker's machine. It can disrupt connectivity, is detectable, and is illegal without authorization. In a lab it is a controlled demonstration of why dynamic ARP inspection and encryption matter.

## Practical notes

In an isolated lab you own, capture remote traffic through a mirrored port or an SSH tunnel. The commands below are examples; adapt interfaces and addresses.

| Command | What it does |
| --- | --- |
| `ssh user@192.168.56.101 "sudo tcpdump -U -s0 -w - 'not port 22'" \| wireshark -k -i -` | Stream a remote capture over SSH into Wireshark. |
| `sudo arpspoof -i eth0 -t 192.168.56.101 192.168.56.1` | Lab-only ARP redirection; requires authorization and clean-up. |
| `sudo sysctl net.ipv4.ip_forward=1` | Enable forwarding so the lab target keeps connectivity during the demonstration. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What is a SPAN port?

A switched port analyser configuration that copies traffic from selected ports or VLANs to a monitoring port.

### Does remote capture require root on the remote host?

Packet capture usually requires elevated privileges. Use an account and method approved by the system owner.
