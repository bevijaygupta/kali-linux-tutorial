## About this chapter

Chapter 9 is a safety lesson disguised as a file-management lesson. It shows mkdir and rm, explains what the -r, -f and -rf options really do, demonstrates rm -i as a confirmation prompt, and warns about the classic mistake of deleting the wrong directory. clear closes the lesson.

- Which mistakes cause irreversible data loss

## Important concepts

### There is no recycle bin

rm unlinks a file immediately. Unlike a desktop trash can, there is no restore step. That is why careful operators verify the path, use tab completion, and prefer rm -i when they are unsure.

### Recursive and forced

The -r flag makes deletion recursive so it can remove directories and their contents. The -f flag suppresses prompts and ignores missing files. Combined as rm -rf, the command is fast, silent and unforgiving — never run it with a path you have not checked.

## Practical notes

Create a disposable directory tree and practise deletion there only.

| Command | What it does |
| --- | --- |
| `mkdir -p lab/notes` | Create nested directories in one command. |
| `touch lab/notes/a.txt` | Create a test file. |
| `rm lab/notes/a.txt` | Delete a single file. |
| `rmdir lab/notes` | Remove an empty directory. |
| `rm -ri lab` | Remove a directory tree with a prompt for each item. |
| `clear` | Clear the terminal display. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Does rm move files to a trash folder?

No. rm deletes the directory entry immediately. Recovering the data requires specialised tools and is not guaranteed.

### Why does rmdir fail?

rmdir only removes empty directories. Use rm -r for a directory that still contains files.
