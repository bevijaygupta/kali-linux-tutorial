## Important concepts

### Reading ls -l

The long format shows permissions, link count, owner, group, size, modification time and name. The first character tells you whether the entry is a directory, a regular file or a link. This output is the starting point for almost every permission problem you will debug.

### Hidden files are a convention

On Linux, a leading dot in a filename hides it from a plain ls. Configuration files such as .bashrc are hidden by convention, not by a special attribute. ls -a reveals them, and ls -la combines that with details.

## Practical notes

Practise these in your home directory and watch how the output changes.

| Command | What it does |
| --- | --- |
| `ls` | List visible entries in the current directory. |
| `ls -l` | Long listing with permissions, owner, size and date. |
| `ls -a` | Include hidden dotfiles. |
| `ls -lh` | Long listing with human-readable sizes. |
| `pwd` | Confirm where you are before listing. |
| `history` | Show recently used commands. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What does ls -lh do differently from ls -l?

It prints file sizes in human-readable units such as KB, MB and GB instead of raw bytes.

### Why can't I see my configuration files?

They start with a dot and are hidden from plain ls output. Use ls -a or ls -la to display them.
