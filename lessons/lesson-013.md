## About this chapter

Chapter 13 handles archives entirely from the terminal. It shows how to zip single and multiple files, compress a whole directory with zip -r, inspect an archive with unzip -l, extract into a chosen directory with unzip -d, and install zip or unzip when they are missing.

## What you will learn

- How to compress one or more files with zip
- How to archive a directory recursively with zip -r
- How to extract archives with unzip
- How to list archive contents without extracting
- How to extract to a specific directory with unzip -d
- How to install zip and unzip if they are missing

## Important concepts

### Archive versus compression

A ZIP file bundles multiple files and compresses them. Extracting restores the directory structure stored inside the archive, which is why paths matter when you create it. Listing the archive first is a safe way to see what it contains before writing files to disk.

### Check before extracting

Archives from untrusted sources can contain unexpected paths. Listing contents with unzip -l and extracting into a dedicated directory reduces the risk of overwriting existing files.

## Practical notes

Practise in a small directory so you can see exactly what each archive contains.

| Command | What it does |
| --- | --- |
| `zip archive.zip file1.txt file2.txt` | Compress two files into one archive. |
| `zip -r project.zip project/` | Compress a directory recursively. |
| `unzip -l project.zip` | List archive contents without extracting. |
| `unzip project.zip` | Extract into the current directory. |
| `unzip project.zip -d /tmp/project` | Extract into a specific directory. |
| `sudo apt install zip unzip` | Install the tools if they are missing. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### What is the difference between zip and tar?

zip both archives and compresses. tar traditionally archives only and is usually combined with gzip or xz for compression.

### Why does zip skip my folder?

Without -r, zip does not descend into directories. Use zip -r to include the folder and its contents.
