## Important concepts

### Memory corruption

A buffer overflow writes beyond allocated memory and can overwrite control data such as a return address. If the attacker controls the overwritten value, execution can be redirected to their code.

### Mitigations raise the bar

Address space layout randomisation, data execution prevention, stack canaries, compiler hardening and prompt patching each complicate exploitation. Many real-world compromises combine a memory bug with an information leak to bypass these protections.

## FAQ

### What is a reverse shell payload?

The target connects back to the attacker's listener, which often bypasses inbound firewall rules. It requires a reachable listener address.

### Why does an exploit fail on a patched system?

The vulnerability may be fixed, the target version may differ from the module's assumptions, or mitigations may prevent reliable exploitation.
