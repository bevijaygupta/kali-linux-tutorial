## Important concepts

### Unix-like, not Unix

Linux was written from scratch by Linus Torvalds and does not contain the original Unix source code. It follows Unix design ideas — everything is a file, small tools combine through pipes, and a powerful shell drives the system — which is why it is described as Unix-like. The UNIX trademark itself is a certification managed by The Open Group.

### Why the distinction matters for security work

Most servers, network appliances and cloud systems you assess run Linux or another Unix-like operating system. Understanding the shared philosophy makes file permissions, processes, logs and the command line easier to learn, and those are the foundations of every later chapter.

## FAQ

### Is Linux a copy of Unix?

No. Linux is an independent kernel inspired by Unix design and combined with GNU userland tools. It shares concepts and interfaces but not the original Unix source code.

### Is macOS Unix?

Yes. macOS is a certified Unix system. Linux is Unix-like but is not certified as UNIX.
