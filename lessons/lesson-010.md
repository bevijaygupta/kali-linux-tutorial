## About this chapter

## Important concepts

### Copying directories requires -r

cp copies files by default. A directory contains other entries, so it must be copied recursively with -r. The -v flag prints each file as it is processed, which is useful when copying a large tree.

### Reading files without an editor

cat prints a file to the terminal and is ideal for short configuration snippets. less opens a pager with search and scrolling, while head and tail show only the start or end. Reading logs often starts with tail.

## Practical notes

Create a small text file, then copy and read it in different ways.

| Command | What it does |
| --- | --- |
| `pwd` | Confirm the working directory first. |
| `cp notes.txt notes-backup.txt` | Copy a file in the same directory. |
| `cp -r lab lab-backup` | Copy a directory recursively. |
| `cp -v notes.txt /tmp/` | Copy with verbose output. |
| `cat notes.txt` | Print a short file. |
| `less /var/log/syslog` | Page through a long file. Press q to quit. |
| `head -n 20 notes.txt` | Show the first 20 lines. |
| `tail -n 20 notes.txt` | Show the last 20 lines. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Why does cp say 'omitting directory'?

You tried to copy a directory without -r. Use cp -r to copy the directory and its contents.

### What is the difference between cat and less?

cat prints the entire file at once. less lets you scroll and search without filling the terminal buffer.
