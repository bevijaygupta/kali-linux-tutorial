## Important concepts

### Small tools, clear signals

Pentbox's honeypot listens on a port and logs connections. Any connection is interesting because there is no legitimate service. Simple decoys like this are useful for learning detection and for early warning on a small network.

### Ruby runtime dependency

Pentbox is a Ruby application, so it needs a working Ruby interpreter. Installing dependencies from a package manager is safer than running arbitrary gem installs as root.

## Practical notes

Install in a lab VM and expose the honeypot only to your isolated lab network. The exact menu choices are demonstrated in the video.

| Command | What it does |
| --- | --- |
| `ruby --version` | Check whether Ruby is installed. |
| `sudo apt install ruby` | Install Ruby from the distribution repositories. |

| `ruby pentbox.rb` | Start the menu-driven interface. |

## FAQ

### Is Pentbox still maintained?

It is an older tool. It remains useful for learning, but check compatibility and prefer maintained alternatives for production monitoring.

### Can a honeypot stop an attacker?

No. It detects and observes. Blocking and containment come from firewalls, segmentation and monitoring systems.
