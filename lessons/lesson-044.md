## About this chapter

- When separate tools give better control than an all-in-one script

## Important concepts

### Convenience versus transparency

All-in-one tools save typing but hide how each check works. You learn more by running WhatWeb, Whois and Nikto separately at least once, then using an aggregator when you understand what it is summarising.

### Third-party code risk

Cloning and running a script executes someone else's code. Review the repository, check for recent maintenance and avoid running unknown scripts as root. The same discipline applies to every tool you install from GitHub.

## FAQ

### Is RedHawk a replacement for Nmap?

No. It focuses on website reconnaissance and basic checks, not full network and port scanning.

### Why run separate tools if RedHawk does the same?

Separate tools give clearer output, better control and a deeper understanding of each check. Aggregators are convenient once you know what they do.
