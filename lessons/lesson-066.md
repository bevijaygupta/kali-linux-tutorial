## Important concepts

### Plugins and configuration

Ettercap's core handles capture and man-in-the-middle positioning; plugins add behaviour such as DNS spoofing. The etter.dns file maps names to addresses, and the plugin must be activated in the running session.

### Privilege and interface choices

Raw capture requires elevated privileges, and the tool must listen on the interface that carries the target traffic. Most setup failures are a wrong interface, an unreadable configuration or a plugin that was never loaded.

## Practical notes

Configure Ettercap on your own lab VM. Read the configuration before changing privilege settings.

| Command | What it does |
| --- | --- |
| `sudo ettercap -G` | Start the graphical interface. |
| `sudo ettercap -T -q -i eth0` | Start console mode on a chosen interface. |
| `sudo less /etc/ettercap/etter.conf` | Review privilege and iptables settings. |
| `sudo less /etc/ettercap/etter.dns` | Review DNS spoof mappings before enabling the plugin. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Where is etter.conf on Kali Linux?

Current packages place it under /etc/ettercap/. Older guides reference /etc/etter.conf, so check the path on your installed version.

### Why does the DNS spoof plugin not appear?

The plugin may not be loaded, the configuration file may be missing or unreadable, or the interface may be wrong. Check the startup log for the first error.
