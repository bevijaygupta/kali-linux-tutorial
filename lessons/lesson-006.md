## About this chapter

Every Kali tool is launched from a shell, so Chapter 6 builds the command vocabulary the rest of the course depends on. It groups 22 essential commands by task — navigation, file creation and deletion, copying and viewing, searching, permissions, and system information — with examples you can run in your own VM.

## What you will learn

- Navigate the file system with pwd, ls and cd
- Create and remove directories and files with mkdir, rmdir, touch and rm
- Copy, move and read files with cp, mv, cat and nano
- Search file contents and the file system with grep and find
- Read text with less and more
- Understand permissions with chmod and chown
- Inspect the system with whoami, uname, uptime, df and du

## Important concepts

### Commands are small and composable

Linux tools do one job and communicate through text. ls lists, grep filters, sort orders and less pages. Pipes let you chain them, which is why a handful of commands can answer complex questions without a dedicated tool.

### Permissions are part of daily work

Every file has an owner, a group and a permission set for user, group and others. chmod changes permissions and chown changes ownership. Security work constantly touches these settings, from making a script executable to understanding why a service cannot read a file.

## Practical notes

Run these in a scratch directory inside your Kali VM. They are the highest-value commands to memorise first.

| Command | What it does |
| --- | --- |
| `pwd` | Print the current working directory. |
| `ls -la` | List all files, including hidden ones, in long format. |
| `cd /tmp` | Change into the /tmp directory. |
| `mkdir lab && cd lab` | Create a directory and move into it. |
| `touch notes.txt` | Create an empty file. |
| `cp notes.txt notes-copy.txt` | Copy a file. |
| `grep -i password notes.txt` | Search a file for text, ignoring case. |
| `whoami` | Show the current user. |
| `df -h` | Show disk usage in human-readable units. |

Commands are shown for study. Run them only in your own lab, read the manual page (`man <tool>`) first, and check every option before executing anything.

<div class="notice notice-warning"><p><strong>Safety and legality:</strong> rm permanently deletes files; Linux has no recycle bin by default. Check your path with pwd before deleting anything.</p></div>

<div class="notice notice-legal"><p><strong>Before you run anything:</strong> destructive commands such as `rm -rf`, interface changes, spoofing and password attacks can break systems or break the law. ## FAQ

### How many Linux commands do I need for Kali Linux?

A few dozen cover most beginner work. Start with navigation, file handling, permissions and text search, then add tools as the course introduces them.

### What is the difference between cp and mv?

cp creates a copy and leaves the original in place. mv moves the file or renames it, so the original path no longer exists.
